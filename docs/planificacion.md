# Planificación del proyecto PowerGym

## Objetivo

Desarrollar una aplicación web que permita gestionar las reservas de clases dirigidas de un gimnasio ficticio.

## Organización del trabajo

El proyecto se realizará de forma individual, con una dedicación estimada de entre 5 y 6 horas semanales.

Las tareas se organizarán en las siguientes etapas:

1. Preparación del entorno y del repositorio.
2. Diseño de la base de datos y de las pantallas.
3. Desarrollo de la aplicación con HTML, CSS, JavaScript, PHP y MySQL.
4. Integración y pruebas de funcionamiento.
5. Corrección de errores y revisión de seguridad.
6. Preparación del despliegue y documentación final.

## Cronograma previsto

El desarrollo se ha planificado de forma orientativa entre noviembre de 2026 y abril de 2027.

Las fechas podrán modificarse según los plazos establecidos por el profesorado y las dificultades que aparezcan durante el desarrollo.

## Seguimiento

Se utilizará GitHub para guardar los archivos y registrar los cambios del proyecto mediante commits.

Las tareas se revisarán periódicamente para comprobar cuáles están pendientes, en proceso o finalizadas.

## Estado actual

El proyecto se encuentra en fase de planificación. Todavía no se ha iniciado el desarrollo de la aplicación.

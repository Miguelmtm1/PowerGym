# PowerGym

## Descripción

PowerGym es un proyecto de aplicación web para gestionar las reservas de clases dirigidas de un gimnasio ficticio.

El objetivo es facilitar a los socios la consulta de actividades y horarios, así como la realización y cancelación de reservas. También permitirá al personal del gimnasio gestionar las clases y controlar las plazas disponibles.

## Funcionalidades previstas

- Inicio de sesión y gestión de usuarios.
- Consulta de actividades y horarios.
- Reserva y cancelación de clases.
- Control de plazas disponibles.
- Gestión de actividades y sesiones por parte del administrador.
- Validación de reservas para evitar duplicados y superar el aforo.

## Tecnologías previstas

- HTML, CSS y JavaScript.
- PHP.
- MySQL.
- XAMPP.
- Git y GitHub.

## Estado del proyecto

Actualmente, PowerGym se encuentra en fase de planificación. Se han realizado el análisis inicial y el diseño de la propuesta, pero todavía no se ha comenzado el desarrollo de la aplicación.
